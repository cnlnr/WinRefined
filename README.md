# Windows-optimization

此项目专门用于 Windows 系统的优化

项目还在完善中

正在寻找共同维护人员，请 Issues 联系我

请克隆此项目到本地：
```shell
git clone https://gitee.com/LZY4/Windows-optimization.git
```

然后进入 `src` 目录

运行相应的系统优化脚本即可

如果报错可能是因为缺少依赖库，请根据错误手动安装

每个脚本的作用在代码前面有说明
