## 安装 

本项目没有打包 exe 需要使用 [Python](https://www.python.org/) 才能运行

下载： <https://gitee.com/LZY4/Windows-optimization/releases>

记得回来看一下有没有新版本

### 安装依赖

```shell
python -m pip install -e . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 开机自启动

打开文件资源管理器，地址栏输入 `启动` 将启动脚本以及快捷方式放到里面
